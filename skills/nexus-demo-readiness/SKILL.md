# NEXUS-Ω Demo Readiness Skill

Use this skill before a 1M1B/IBM SkillsBuild demo, evaluator review, or major presentation.

## Checklist
1. Confirm the first screen answers an ordinary user's immediate question: what can affect me and what should I do next?
2. Verify all simulated or synthetic values are clearly labeled as demo data.
3. Check every important result includes meaning, cause, dependencies, evidence, next step, time, impact, recommended action, reason, alternatives, expected result, and confidence when applicable.
4. Verify consequential actions require human approval and official emergency guidance is not overridden.
5. Verify no sensitive user/location data is logged unnecessarily.
6. Test mobile layouts, large circular touch targets, tablet-style cards, keyboard focus, and readable text.
7. Test the evaluator demo flow: Daily view → Ask NEXUS → Route Guardian → Family → Emergency Copilot → Ω-CORE / Break the Chain.
8. Identify broken buttons, dead links, placeholder values, API failures, and misleading live-status claims.
9. Produce a short pass/fail report with exact fixes required before demo.
